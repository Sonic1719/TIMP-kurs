# Курсовая работа по дисциплине ТИМП
## Сетевой сервер для вычисления произведений векторов

Консольное многомодульное сетевое приложение типа «Сервер» под операционную систему Linux.

### Параметры варианта:
* **Тип вычислений:** Произведение элементов вектора
* **Тип данных:** Числа с плавающей точкой (`float`)
* **Алгоритм хэширования:** SHA-1
* **Формирование соли:** На стороне сервера

### Структура проекта:
* `main.cpp` — Главный модуль приложения, инициализирует класс `ServerApp` и разбирает параметры командной строки с помощью библиотеки **Boost::program_options**.
* `server.cpp` / `server.h` — Реализация ООП-компонентов сервера:
  * `ServerCommunicator` — отвечает за создание сокетов, привязку к порту и сетевое ожидание.
  * `AuthManager` — отвечает за безопасную авторизацию с использованием библиотеки **Crypto++**.
  * `Calculator` — вычисляет произведение элементов векторов с обработкой переполнения типа `float`.
  * `Logger` — записывает реальные ошибки в файл `vcalc.log`.
* `Makefile` — Скрипт раздельной компиляции для автоматической сборки проекта на стандарте **C++14**.

### Инструкция по сборке и запуску:

1. Сборка сервера:
```bash
make
```

2. Запуск сервера:
```bash
./server_static -T float -H SHA1 -S server
```

3. Очистка временных файлов компиляции:
```bash
make clean
```
